JFReD — Claude Code session debugger (demo)

What this is: the JFReD JSONL debugger running the frozen legacy engine (the archived api/ modules) entirely in your browser — no server. It is not Engine B, the current reconstruction engine in this repository's src/; see the repo README for the live webapp.
Engine-B demo: the current reconstruction engine's viewer over the same s87-demo-composite capture — a canned, pre-built reconstruction served as static data (no server; diff/range-patch actions that need a live engine show a "not available in the static demo" notice).

Pick a session from the preloaded s87-demo-composite capture — a scripted multi-session Claude Code scenario (edits, script runs, renames, rewinds) recorded specifically for this demo. Each link opens the debugger with that session's JSONL already loaded; you can also load any local JSONL with the Open button once inside.
